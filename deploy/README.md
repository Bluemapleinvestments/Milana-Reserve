# Milana Reserve — Investor Memorandum

Interactive investor presentation for Milana Reserve, a 232-unit multifamily acquisition in Tampa, Florida.

## Live site
Deployed via Netlify from this repo on every push to `main`.

## File structure
- `index.html` — **production build** (fully self-contained; this is what Netlify serves)
- `milana-reserve-source.html` — editable source that loads from `/src`
- `src/` — React (JSX) components (editable source)
- `styles.css` / `styles-standalone.css` — stylesheets
- `assets/` — logos and images
- `netlify.toml` — Netlify build configuration
